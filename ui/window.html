Connections

      
Push Surface runs on your computer and sits between the Push 2 and the disting NT. Both plug into the computer over USB; they never connect to each other.

      
      
    
        
  • Push 2: USB to the computer, plus its own power adapter so the pads and screen run at full brightness.
    • 
        
  • disting NT: USB-C socket (left of its display) to the computer. The rack must be on; the NT takes no power over USB. The same cable carries MIDI, which Push Surface uses, and audio, which Live can use.
    • 
        
  • Audio: optional and separate. Push Surface doesn't touch audio.
    • 
      


      
First setup

      
    
        
  1. Plug in both devices as above, then open Push Surface. The Status tab should show three green lights.
    2. 
        
  2. On the disting NT, check Settings → SysEx Device ID is 0, or set sysExId to match (Status tab → Settings).
    3. 
        
  3. Optional: turn on SysEx changes in the NT's Settings menu, so the module's screen jumps to whatever you turn on the Push.
    4. 
        
  4. To try it with no module, choose Demo on the Status tab.
    5. 
        
  5. Windows, Push screen: the screen needs Ableton's Push 2 display driver. Live installs it the first time it runs with the Push connected. Without Live, install the WinUSB driver for the Push 2's display interface with Zadig.
    6. 
      

      
Push Surface switches the Push to User mode when it connects, and back to Live mode when you quit.

      
Windows: Push Surface talks to the Push through its second MIDI port, MIDIIN2/MIDIOUT2 (Ableton Push 2).


      
Using it while Ableton Live is running

      
Live's own Push 2 support grabs the Push as soon as Live starts: it switches the Push to Live mode and takes its screen. Push Surface keeps running but loses control. To run both at once, tell Live to leave the Push alone:

      
    
        
  1. In Live, open Settings → Link, Tempo & MIDI (Live 11: Live → PreferencesOptions → Preferences).
    2. 
        
  2. Under Control Surface, change the row set to Push2 to None, and set that row's Input and Output to None.
    3. 
        
  3. In the MIDI Ports list, turn Track and Remote off for both Ableton Push 2 ports (Live Port and User Port), so Live doesn't also react to the pads.
    4. 
        
  4. Back in Push Surface, press Reload, or quit and reopen it, so it takes the Push and its screen back. The Push screen light turns green.
    5. 
      

      
Live keeps working with the disting NT alongside Push Surface; both can talk to it at once.

      
Windows: a classic MIDI port can be open in only one app at a time, unless your Windows 11 has the newer multi-client MIDI (Windows MIDI Services). If the disting NT light stays amber while Live is open, turn the disting NT's ports off in Live's MIDI Ports list too.

      
    
        
  • Sequence the NT from Live: in MIDI Ports, turn Track on for the disting NT output, then send a MIDI track to it.
    • 
        
  • Record or play audio through the NT: choose disting NT as Live's audio device, or an Aggregate Device with your interface, and add the NT's USB audio (to host) and (from host) algorithms (Windows needs Expert Sleepers' audio driver for this). On the NT, turn on Settings → Engine → Allow USB rate change.
    • 
      

      
To use the Push for Live again, set the Control Surface back to Push2 and quit Push Surface. Live remembers these settings, so you only change them when you switch.

Modes

      
Press a mode button to enter it; press it again, or Device, to go back.

      
Add Device

      
Every algorithm the module knows, built-ins and plug-ins. Turn encoder 1 or Master to scroll; encoder 2 jumps by first letter. Press Select or Add. If the algorithm has options (channels, voices, buffer size), set them on the next page with the encoders and press Add. The new slot goes at the end.

      
Browse

      
The /presets folder on the SD card, folders first. Scroll with encoder 1, Master or ▲ ▼ (Page ◀ ▶ jumps 5). Buttons below: Load, Append (adds its slots to the current preset), Up, Close.

      
Mix: performance page

      
The NT's performance-page parameters, 8 at a time with their own labels; the buttons below pick each group of 8. Needs NT firmware 1.16 or later.

      
Automate: mappings

      
CV, MIDI and I2C mappings of the last parameter you touched or turned. Buttons below pick CV, MIDI or I2C; encoders set channel, type, CC, range and so on. Changes go to the module as you turn.

      
Clip: the NT's front panel

      
Shows the NT's own screen and turns the Push into its controls, so you can reach every menu on the module.

      

        
Push 2disting NT

        
Encoders 1–3Left, centre, right pot (Shift = fine)

        
Encoders 4–5, MasterLeft encoder, right encoder

        
Buttons above the screen 1–5Press left / centre / right pot, left / right encoder

        
Buttons below the screen 1–4Buttons 1–4

      

      
Scale

      
Pad settings: Root, Scale (12, from Major to Whole tone), Layout (Chromatic or In key), Velocity (Dynamic or Fixed) and the MIDI channel the pads play on. Done returns.


      
Pads

      
    
        
  • Note (default): play the NT's synth algorithms, with velocity and poly aftertouch. Chromatic layout = a semitone per pad, a fourth per row, C pads lit. In key = only the scale's notes. Set the algorithm's MIDI channel to match the pads (default 1).
    • 
        
  • Session: each column is a slot, each row one of its pages; tap to jump there. Current = orange, bypassed = red.
    •

    •

    •

    •

    • 
      

      
Closing the window or pressing ⌘Q quits Push Surface and hands the Push back to Live mode.
